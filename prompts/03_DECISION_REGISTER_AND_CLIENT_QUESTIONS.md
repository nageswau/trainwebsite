# 03 — Decision Register and Client Questions

Read:
- evidence register
- conflict matrix
- scope delta
- UX reference audit
- decision register template

NO CODE.
DO NOT MAKE THE DECISIONS YOURSELF.

Create `docs/decisions/PRODUCT_DECISION_REGISTER.md`.

Every unresolved item starts UNCONFIRMED.

For each decision provide:
- Decision ID
- business/technical question
- exact evidence supporting each option
- impact of each option
- dependencies affected
- recommended option, if evidence supports a recommendation
- what must be confirmed by user/client
- status

Create a concise `docs/decisions/CLIENT_QUESTIONS.md` grouped into:
1. scope
2. roles
3. Overseas/Agent
4. learning/live classes
5. payments/finance
6. notifications/integrations
7. privacy/security
8. technology/cloud
9. UX authority
10. delivery/timeline

Never convert a recommendation into an approval.

STOP and request approval of high-impact decisions before BRD.
