# ENH-021 / ENH-026 — Browser QA record (2026-09-28)

**Scope:** exploratory QA of ENH-021 (internships) and ENH-026 (counselling record) on branch
`feature/enh-021-026-internship-counselling-record`, then one fix pass and a browser re-test.

**Environment:** isolated Compose project `enh021-026` (web :3260, API :8260, own Postgres), an isolated Chrome
(throwaway profile, CDP :9333) driven by Browser Use. Throwaway Platinum, Gold and second-Platinum schools created
through the API; two legacy rows (a status-NULL counselling note, a pre-ENH-021 internship at the Gold school) inserted
directly into the isolated database because the application can no longer create them.

**Covered:** happy path, invalid inputs, empty states, injected 500 and connection reset, loading under a throttled
network, cancel/Escape/back, refresh, triple-click duplicate submission, signed-out access, wrong roles (psychometric
team, coordinator on the counsellor page, unassigned teacher, other parent, other-school counsellor and coordinator),
desktop 1440 / tablet 768 / mobile 375, navigation, success and error messages, broken images, console errors, failed
network calls, unexpected redirects. **Not covered:** a real backend outage (simulated by interception), browsers other
than Chrome, screen readers.

tracking fields in edit; QA-10 busy skeleton rendered with the navigation; QA-12 18 px gap; QA-15 distinct names
("Edit counselling note of 28 Sept 2026 for …", "Edit guidance session of …"). No console errors or unexpected
failed requests during the re-test.
