# IT Counselor CRM — User Manual

How an IT counselor works in EduSphere: from a lead the telecaller hands over, through counselling and conversion, to looking after the IT student's fees, resume and progress. Every page was checked against the running application (`main` @ `6b61546c`) with fictional **Docs** test data.

**New to the portal?** Read [Sign in](account-access/auth-001-sign-in.md), then the [Portal tour](navigation/nav-001-portal-tour.md), then the [IT counselor role guide](../role-guides/it-counselor.md).
