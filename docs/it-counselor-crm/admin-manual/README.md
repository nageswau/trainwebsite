# IT Counselor CRM — Administrator Manual

The IT Admin's (and, where noted, the Super Admin's and Telecaller Manager's) side of the IT Counselor CRM: counselor accounts, students and their counselors, leads, fees, HR reviews, at-risk rules and settings. It also explains the hand-offs between telecallers, counselors, students and HR. Verified against `main` @ `6b61546c` with fictional **Docs** data.

Owner decision I1: only the counselor-related IT Admin and Super Admin screens are covered.
