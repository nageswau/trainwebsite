# Demo and Docs accounts

The screenshots in this set were taken with fictional **Docs** accounts and records, created through the application's own screens on a separate documentation stack. This page maps them to the seeded demo accounts you can use to try the same flows on a demo or training system.

No passwords are recorded here. Docs accounts set their own passwords from the welcome email; seeded demo accounts use the demo password your administrator gives you.
