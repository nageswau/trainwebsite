# Approval Gates

No gate may be inferred from Claude's own recommendation.

## GATE-01 — Evidence Audit
Required:
- source manifest
- duplicate analysis
- conflict matrix
- UX-reference accessibility status

## GATE-02 — Product Decisions
Required:
- high-impact decisions explicitly confirmed or blocked

## GATE-03 — BRD
Required:
- business scope, roles, workflows and exclusions approved

## GATE-04 — PRD
Required:
- functional/NFR requirements approved

## GATE-05 — Feature Catalogue
Required:
- current-release Feature IDs and acceptance criteria approved

## GATE-06 — UX / Screen Catalogue
Required:
- required routes/screens/flows approved
- Canva reference authority explicitly stated

## GATE-07 — Architecture
Required:
- stack, architecture style and cloud/provider decisions approved

## GATE-08 — Contracts / Test Strategy
Required:
- DB/API/RBAC/integration contracts and rewritten test strategy approved

## GATE-09 — Coding
Only after Gates 01–08.

## GATE-10 — Release
Only after implementation, automated quality gates, UAT and operational readiness.
