## Rigor note carried into this log

Several NFRs in PRD 1.0 (`NFR-PERF-001` response time, `NFR-SCALE-001` scalability,
`NFR-A11Y-001` accessibility standard) are marked **PROPOSED**, not confirmed, because their only
source is either a derived document's self-description or an informal transcript comment that was
never put through the Decision Register. Any future version that upgrades one of these to
CONFIRMED_CURRENT must cite the specific user confirmation that did so, in this log, the same way
`docs/product/BRD_CHANGE_LOG.md` requires for BRD changes.

## Change-control rule for future entries

Every future row must cite the Decision ID or explicit user confirmation that authorized the
change. No entry may be added on the basis of a draft test case or an unconfirmed recommendation.
