## Baseline practices applied to every screen (good practice, not a specific conformance claim)

- **Keyboard navigation:** every interactive element (links, buttons, form fields, menus) reachable
  and operable via keyboard alone, in a logical tab order.
- **Visible focus states:** every focusable element has a clearly visible focus indicator — never
  suppressed for aesthetic reasons.
- **Form labels:** every input has an associated, programmatically-connected label (not
  placeholder-text-only).
- **Colour contrast:** sufficient contrast between text and background for readability (exact ratio
  target open pending `NFR-A11Y-001` confirmation).
- **Error identification:** validation errors are announced in text (not colour alone) and
  associated with the specific field.
- **Alt text:** meaningful images carry descriptive alt text; decorative images are marked as such.
- **Semantic structure:** headings, lists, and landmarks used semantically, not just visually
  styled `<div>`s — supports screen-reader navigation.

## Screens with distinctive accessibility needs

| Screen(s) | Requirement |
|---|---|
| `SCR-STU-001` (slot booking), `SCR-AGT-005` (commission claim), `SCR-ADM-002` (user deactivation) | Destructive/high-consequence actions (locking a slot, claiming a payout, deactivating a user with dependents) need an explicit, keyboard-reachable confirmation step, not a hover-only or mouse-only interaction |
| `SCR-STU-003`, `SCR-TRN-003` (live-class join) | Join controls must not rely on colour alone to indicate "live now" vs. "not yet started" — include a text state |
| `SCR-STU-014`, `SCR-OVS-007`, `SCR-VISA-001` (file upload) | Upload progress and success/failure states announced to assistive technology, not just visually |
| `SCR-ADM-002`, `SCR-EMP-004` (data tables/search) | Sortable/filterable tables expose their sort/filter state to assistive technology, not just visually (e.g. an icon-only sort arrow) |
| `SCR-SEC-001` (GDPR export/delete) | A consequential, hard-to-reverse action — needs explicit confirmation and clear plain-language copy, not jargon |
