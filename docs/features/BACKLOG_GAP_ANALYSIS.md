**Net effect:** the blueprint's specific task breakdown was not used as a source for this
catalogue's features. Every feature here traces to PRD/BR/Decision IDs directly, per

phases (`docs/decisions/CONFLICT_MATRIX.md`, `SCOPE_DELTA.md`) but its task-level detail was not
imported.
