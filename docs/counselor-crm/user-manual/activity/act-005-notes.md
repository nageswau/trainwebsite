# Lead notes
> Doc ID: DOC-CNS-ACT-005 · Verified on 2026-10-30 against `main` @ `045d8c40` · Roles: Counselor

## Purpose
Keep internal notes about a lead, such as budget, family decisions or preferences, that don't belong to a call or meeting.

## Who Can Use This Feature
The counselor who owns the lead. Notes are internal; the student never sees them.

## Prerequisites
None. You can add notes on closed leads too.

## How to Access
Lead page → **Notes**.

## Steps
### Step 1 — Write the note
Type in **Add a note** (up to 4000 characters; a counter shows how many you have used).

### Step 2 — Add it
Select **Add note**. **Note added.** appears and the note is listed under **Lead notes**, newest first, with your name and the time.
![Lead notes](../../screenshots/activity/10-notes.png)

## Fields
| Field | Description | Required | Example |
|---|---|---|---|
| Add a note | Up to 4000 characters | Yes | Father will fund the course; budget around ₹25 lakh… |

## Expected Result
The note stays on the lead permanently. Notes can't be edited or deleted.

## Validation Messages
| Message | When |
|---|---|
| Note added. | Success |
| Write a note first. | Empty note |

## Tips
- Write notes so a colleague could pick up the lead tomorrow.
